Add complete lazy Submodel contracts, implementations, and application-owned hosts. Typed preparation Messages admit child execution for a matching build, instance, and attempt. Hosts support prefetch, retry, parked state, and an explicit preparation barrier for restored Models.

Add runtime preparation, restoration resumption, and dynamic subscription selection. Each selected subscription retains its own dependency reference and cleanup lifecycle.

Add typed Submodel catalog generation from explicit contract files. The Vite plugin checks generated catalogs and diagnoses eager execution imports, cross-route implementation imports, and route execution in startup chunks. It also supplies a build identity and emits a Submodel manifest.
